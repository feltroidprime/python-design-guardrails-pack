Validated on macOS Apple Silicon with Python 3.14.6, uv 0.11.28, just
1.56.0, Bun 1.3.9, Git 2.55.0, Copier 9.17.0, pytest 9.1.1, and

because the canonical template changes were intentionally uncommitted.

## Change validated

The derived LikeC4 architecture model became an **opt-in feature that is off by
default**, selected with `python-repo init --likec4` (Copier question `likec4`).

Without the flag, a generated repository contains no `docs/architecture/likec4/`,
no `scripts/sync_architecture_diagrams.py`, no `diagram *` gate checks, no
`just diagrams`, no `grimp` dev dependency, no `[tool.likec4]` pin, no CI
`setup-bun` step, and no ADR-0006 — so **Bun is no longer a prerequisite** of a
generated repository. Import Linter enforces the same layer contract in both
configurations.

Two supporting changes were required:

1. The shipped ADRs were renumbered so the optional decision sits last
   (0002–0006 → 0001–0005; derived diagrams → 0006). This keeps the docs
   guard's contiguous-numbering rule (DOC006) satisfied whether or not the
   optional ADR ships.
2. The docs guard's derived-documentation exclusion is now any `generated/`
   directory under `docs/`, rather than the LikeC4 path specifically.

## Remaining risks and portability notes

- **ADR renumbering is a breaking change for existing generated repositories.**
  `just scaffold-update` will present the five renames; downstream
  `ARCH-EXCEPTION: ADR-NNNN` markers pointing at template ADRs must be adjusted
  in the same commit, and repositories with their own ADRs at 0007+ should
  check for collisions before merging.
- The LikeC4 configuration is not exercised by the default `just validate`; a
  change to any `likec4`-conditional branch requires `just validate likec4`,
  which keeps Bun and first-`bunx`-download network access as prerequisites for
  that run only.
- Three previously verbatim template files are now Jinja-rendered:
  `scripts/quality_gate.py.jinja`, `.github/workflows/quality.yml.jinja`, and
  `docs/architecture/README.md.jinja`. `scripts/docs_guard.py` deliberately
  stayed verbatim — the pack's own tests import it as a module — which is why
  its exclusion rule was generalized instead of made conditional.
